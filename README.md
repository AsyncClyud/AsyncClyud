**FlaBaxxit** — псевдо-социальная сеть на Go!

О проекте:

- Слоистая архитектура: repository → service → handler
- Gin + pgx, PostgreSQL для хранения, Redis для кеширования
- JWT-аутентификация с middleware для защищённых роутов.
Прошёл нагрузочное тестирование и проверку на SQL-инъекции.
